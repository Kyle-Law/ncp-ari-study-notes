Verifying power capacity by PDU type

A rack PDU's capacity comes from its input: phase, voltage and amps. Intelligence (metered, monitored, switched) changes what you can see and control, not how much power you get. Then the smallest limit in the chain sets the real ceiling.

Exam objectiveVerify the power capacity by PDU type.

In one minute

  • Single-phase: kVA = V × A ÷ 1000. Three-phase: kVA = √3 × Vline-line × A ÷ 1000. Same amps, three-phase delivers about 3× a single-phase circuit at the line-to-neutral voltage.
  • Usable continuous capacity is typically 80% of the breaker (NEC continuous-load rule in North America; many operators apply the same margin elsewhere).
  • kW ≈ kVA × power factor. Modern server PSUs run at about 0.95–1.0, so kW ≈ kVA for planning.
  • The real limit is the smallest of: upstream breaker and receptacle, PDU input rating, internal branch breakers, and outlet ratings (C13 ≈ 10–15 A, C19 ≈ 16–20 A).
  • PDU types by feature: basic → metered (local display) → monitored (network, per-unit or per-outlet metering) → switched (remote outlet on/off). Use the metering to verify actual load against capacity.

Capacity comes from the input, not the features

A basic and a switched PDU with the same 208 V 3φ 60 A input have the same ~17.3 kW usable capacity. The intelligent one lets you prove you're within it, with per-phase readings and threshold alarms before a breaker trips.

Find the weakest link

A PDU only delivers what its narrowest point allows. Example: a 208 V 3φ 60 A PDU with six 20 A branch breakers feeding C13 and C19 outlets.

Upstream breaker 60 A 3φ→ PDU input 60 A (≈ 17.3 kW usable)→ Branch breaker 20 A (≈ 3.3 kW usable at 208 V)→ C19 outlet 16–20 A→ Device PSU

The whole PDU can deliver ~17.3 kW, but no single branch can supply more than ~3.3 kW continuously. A GPU server with several PSUs has to be spread across branches. Check each branch, each phase, and the total.

Exam traps

  • Forgetting √3.208 V × 60 A = 12.5 kVA is wrong for three-phase. It's √3 × 208 × 60 ≈ 21.6 kVA.
  • Planning to 100%.Continuous load on a standard breaker: 80%. 21.6 kVA → ~17.3 kVA usable.
  • "Switched PDUs have more capacity."Features don't change capacity. The input rating does.
  • Ignoring branch breakers.A rack can be under the PDU total but over a branch.
  • Using the phase-to-neutral voltage in the 3φ formula.Use line-to-line (208 / 400 / 415 V) with √3, or phase-to-neutral × 3 × A (same result).

Check yourself

1. Usable continuous capacity of a 208 V three-phase 30 A PDU (80% rule)?

√3 × 208 × 30 ≈ 10.8 kVA nameplate; × 0.8 ≈ 8.6 kVA.

2. Which feature distinguishes a switched PDU from a monitored one?

Both can meter per outlet. Switched adds remote outlet control.

3. A 230 V single-phase 32 A PDU: nameplate capacity?

230 × 32 = 7,360 VA. Single-phase has no √3.

4. A rack totals 12 kW on a 17.3 kW-usable PDU, but one branch trips. Why?

Each branch breaker is its own limit. Spread load across branches and phases.
