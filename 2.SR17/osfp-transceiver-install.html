Installing an OSFP transceiver in a SAN director

A walkthrough of the IBM Storage Networking procedure: seat the module, plug in the cable, confirm the link light, and keep the cabling tidy.

The IBM page blocks automated access, so this guide is built from the identical Broadcom procedure it is based on (IBM b-type SAN directors are Brocade hardware): Brocade X8-8 Director — Installing an OSFP Transceiver. Original IBM link: ibm.com/docs.

What an OSFP is

OSFP (Octal Small Form-factor Pluggable) is a hot-pluggable module that turns the switch's electrical signal into light for a fibre cable. "Octal" means eight electrical lanes, which is why it is the widest and fastest of the common pluggable formats. It has its own heat sink on top, so it runs warm. On directors, OSFP ports are typically used for high-bandwidth inter-chassis links rather than ordinary device ports, which use SFP+.

Before you start: qualified modules only

The director accepts only transceivers qualified for Brocade (IBM b-type) hardware. An unqualified module will physically fit but won't come online.

You can spot this in the switchshow command output: the port reports the state Mod_Inv (module invalid), and Fabric OS also writes an entry to the system error log.

admin> switchshow Index Port Address Media Speed State ====================================== ... 384 0 ------ id N32 Online 385 1 ------ -- -- Mod_Inv ...

Illustrative output. Column layout varies by model and firmware.

The procedure, step by step

Side view of one port. Use Next to walk through it, or try inserting the module the wrong way up to see why keying matters.

Module out of the port.
  1. 1

    Push the transceiver in by its pull tab

    Modules are keyed and fit only one way up. If it doesn't slide in easily, check the orientation rather than forcing it. Push until it seats firmly and the latch clicks. Always handle it by the pull tab: an OSFP can be hot.
  2. 2

    Insert the cable, key to slot

    Line up the key (the ridge on one side of the cable connector) with the slot in the transceiver and push until it clicks. The port LED shows steady amber while the link is not yet up.
  3. 3

    Wait for steady green

    Once both ends of the cable are plugged in and the link is established, the LED turns steady green.
  4. 4

    Dress the cables

    Route cables so they don't cover the port LEDs or the air vents. Use the director's cable management fingers.

Keying: one way in

Both the module and the cable are keyed. Seen head-on, the connector's ridge must meet the slot in the transceiver face.

Don't force a mismatched cable. Never plug a cable meant for a different kind of transceiver into a regular OSFP module; you can damage both.

Reading the port LED

Steady amber
Cable in, but the link isn't up yet (for example, the far end isn't connected).
Steady green
Both ends connected and the link is fully established.
Stuck on amber?
Check the far end, reseat both connectors, and run switchshow to look for Mod_Inv.

Cable dressing: good vs. bad

Quick checklist

  • Transceiver is qualified for this director.
  • Module handled only by its pull tab and inserted the right way up.
  • Module latched with an audible click.
  • Cable key aligned with the transceiver slot and latched.
  • Far end connected; port LED steady green.
  • switchshow shows no Mod_Inv on the port.
  • Cables routed through management fingers, clear of LEDs and vents.
