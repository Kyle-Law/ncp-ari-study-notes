NVIDIA installation standards and warranty compliance

NVIDIA publishes how its clusters should be cabled and handled. Following those documents keeps the system supported. Ignoring them, through the wrong installer, unvalidated parts or damaged cables, can leave you paying for the failure.

Exam objectiveFollow NVIDIA-specific installation standards (DU-10438, warranty compliance).

In one minute

  • DU-10438-001 is NVIDIA's "Cabling Data Centers" design guide (DGX SuperPOD). It covers cable management best practices, deploying bundles, and maintaining NDR connectors. These are the 4 · SR3 / SR4 / SR5 readings.
  • Its core rules: 50/50 left/right routing, nothing across the rack centre, plug bottom-up, connect and dress per U, hook-and-loop only, supports ≤ 60 cm, no twist within 75 cm of a connector, clean every insertion, keep parts reachable and air flowing.
  • Companion: NVIDIA's Cable Installation and Management Guidelines (5 · SR2): bend radius, no hanging > 2 m, ties every 30–60 cm, install one/test one, runs < 90% of rated reach, ESD and humidity on unpacking.
  • Warranty: DGX installation must be done by NVIDIA field engineers or an NVIDIA partner, or the hardware warranty is void. Use validated cables/optics for support. Damage from improper installation (e.g. over-bending) is typically excluded.
  • Keep records (as-builts, test results, photos) as proof of compliant installation.

Warranty and support essentials

Authorised installers

DGX systems: installation by NVIDIA field engineers or an NVIDIA partner, or the hardware warranty is void (DGX H100/H200 user guide).

Validated parts

Use cables and transceivers from the firmware's validated list. Third-party parts carry no performance guarantee and aren't handled through normal support.

Handle to spec

Bend radius, pulling tension, ESD and storage humidity per datasheets. Damage from improper installation is typically excluded from warranty.

Keep proof

As-builts, test results, inspection images and photos show the installation met the standard if a claim is ever questioned.

Exam traps

  • "Any certified electrician can install the DGX."NVIDIA requires its field engineers or an NVIDIA partner for DGX installation, or the warranty is void.
  • Confusing DU-10438 with the NEC.DU-10438 is NVIDIA's own cabling design guide. Codes like the NEC still apply alongside it.
  • "Clean at first install only."The NDR maintenance section says every insertion.
  • Zip ties for neatness.Hook-and-loop only.

Check yourself

1. What is NVIDIA DU-10438-001?

It's NVIDIA's cabling design guide (cable management, deploying bundles, NDR connector maintenance).

2. Who must install a DGX system to keep the hardware warranty?

Per the DGX H100/H200 user guide, otherwise the hardware warranty is void.

3. Maximum spacing between cable supports in the guide's dressing rules?

Within the rack dressing guidance: supports at 60 cm or less. (5 ft is tray support spacing, 2 m the general hanging limit.)
