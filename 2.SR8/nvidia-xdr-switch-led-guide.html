Four status LEDs, one rule of thumb

The LEDs are the switch's first line of hardware event notification and troubleshooting. Across every indicator the language is consistent: green means healthy, amber means something needs attention, and blue is only ever the locator light you turn on yourself.

Normal: green, flashing green while booting
Power supply / DC busbarHealth of the PSUs or DC busbar feed.
Normal: green

Normal: green

Normal: off, blue while identifying

System status LED

Located on the front panel. Booting can take up to five minutes, so a flashing green light right after power-on is expected.

Fan status LEDs

Fans are reported twice. The single front LED summarizes all fans; on the rear, each fan module has its own LED, which is how you find the one that failed.

Front LED (all fans)

LEDMeaningWhat to do
Solid greenAll fans are running.Nothing
Solid amberOne or more fans are not operating properly.Replace the faulty FRU(s).

Rear LEDs (one per fan)

LEDMeaningWhat to do
Solid greenThis fan unit is operating.Nothing
Solid amberThis fan unit is missing or faulty.Replace that fan unit.
Risk of electric shock. With a fan module removed, power pins are exposed inside the empty cavity. Keep tools and fingers out of it.

Power supply and DC busbar LEDs

The switch has redundant power inlets and cannot run on a single connected supply. As with fans, there is a front summary LED plus one two-color LED on each rear PSU. DC busbar models (Q3401-RD, Q3450-LD) have no rear PSU LEDs.

Front LED (summary)

LEDMeaning and action
Solid greenAll plugged-in supplies are running normally.
Solid amberOne or both supplies are down, unpowered, or unplugged. Check the power cord is plugged in and live; if it persists, replace the FRU.

Rear LED (per PSU, AC models)

LEDMeaning and action
Solid greenPSU connected and running normally.
Green, 1 HzAC present but only standby (12VSB) on, PSU off or in Smart-on state. Call NVIDIA.
AmberAC cord unplugged or AC lost on this PSU while the other still has power: plug it back in. Or PSU failure, including out-of-range voltage: check voltage, then call NVIDIA.
Flashing amberWarning, but still running: high temperature, power or current, or a slow fan. Call NVIDIA.
OffNo AC power to any supply. Call NVIDIA.

Unit identifier (UID) LED

In a cluster of identical switches, the UID LED is how you find the one you are logged into. You turn it blue from the CLI, walk the aisle, then turn it off again.

# turn the locator light on
switch (config) # led MGMT uid on

# check it
switch (config) # show leds
Module   LED    Status
--------------------------------
MGMT     UID    Blue

# turn it off when you're done
switch (config) # led MGMT uid off

Port LEDs (InfiniBand mode)

Each data port has an LED that tracks the link as it comes up. Physical connection comes first (amber), then the Subnet Manager (SM) brings up the logical link (green), and traffic makes it blink.

OffLink down. Check the cable.
cable plugged into a live port
Solid amberPhysical link up. Wait for the logical link; make sure the SM is running.
SM brings up logical link
Solid greenLink up, no traffic.
data flows
Flashing greenLink up with traffic.
  Flashing amber means a problem with the link. Start by checking that the SM is up.

These systems also have one extra OSFP port for Fabric Network Management (FNM), with its own dedicated LED. Its position differs between the Q3200-RA, Q3400-RA/Q3401-RD and Q3450-LD; see the photos in the original manual.
