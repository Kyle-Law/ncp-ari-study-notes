NVIDIA Networking, explained

In plain terms This is NVIDIA's landing page for everything that moves data between GPUs. Its argument: once an AI system spans thousands or millions of GPUs, the network, not the chips, decides how fast the whole thing runs. NVIDIA sells the full set of parts — cables, switches, network cards, data-processing chips and management software — designed together so the GPUs never sit waiting.

Three distances, three kinds of network

The page's central idea is that one AI system is wired at three distances at once. Pick one to see what gets connected and which NVIDIA product does the job.

Why the network sets the pace

Training a model is a loop: every GPU computes its share, then all of them swap results before the next step can begin. The step only ends when the slowest message arrives. A network with unpredictable delays (what the page calls tail latency) leaves every GPU idle while it waits. That is why NVIDIA stresses predictable latency, no dropped packets and steady iteration times rather than raw speed alone.

Two ideas worth a closer look

BlueField DPU: a helper chip for the plumbing

A data processing unit sits in each server and takes over networking, storage and security work that would otherwise steal time from the main CPU. The page frames BlueField-4 as the processor running the "operating system" of an AI factory; DOCA is the software kit for programming it.

ApplicationsInfrastructure chores

Co-packaged optics: light, closer to the chip

Today a switch's chip sends electrical signals across a circuit board to plug-in optical modules at the front panel. Co-packaged silicon photonics puts the light-converting parts right beside the switch chip. Shorter electrical paths waste less power, which NVIDIA says lets networks grow to millions of GPUs.

The six promised benefits

Performance

Keeps GPUs busy by cutting the slow outlier messages that stall each training or inference step.

Gigascale

Large switches, optics in the chip package and Spectrum-XGS let whole campuses behave as one system.

Security and visibility

Isolates tenants and data, and shows operators exactly what's flowing through the network.

Orchestration

NetQ, UFM and DOCA turn network telemetry into automated monitoring and threat analytics.

Simulation

DSX Air builds a virtual copy of a data center network to test designs and policies before buying hardware.

Efficiency

Lower power per bit through co-packaged optics and processing work inside the network itself.

Jargon decoder

AI factory
NVIDIA's term for a data center built mainly to train and run AI models.
NVLink
NVIDIA's very fast GPU-to-GPU link, used inside a server or rack.
InfiniBand
A low-latency networking standard popular in supercomputers.
NIC / SuperNIC
The network card in each server; a SuperNIC is NVIDIA's AI-tuned version.
DPU
Data processing unit: a chip that handles networking, storage and security for the server.
Tail latency
The delay of the slowest messages. In AI training it sets the speed of every step.
Lossless
A network that avoids dropping packets, so nothing has to be resent.
NCCL
NVIDIA Collective Communications Library, the software GPUs use to exchange results.
Co-packaged optics
Optical components built into the same package as the switch chip.
RAG
Retrieval-augmented generation: an AI model that looks things up before answering. Named in the page's description as a target workload.
